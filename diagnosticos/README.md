# Diagnósticos Smart City

Este directorio contiene todos los diagnósticos completados.

## Estructura

- `datos/` — Archivos JSON de cada diagnóstico
- `index.php` — Panel para ver/exportar diagnósticos
- `.gitkeep` — Asegura que la carpeta se cree en Git

## Formato de archivos

Cada diagnóstico se guarda como JSON con el nombre:
`diagnostico_FECHA_MUNICIPIO.json`

Ejemplo: `diagnostico_2026-07-15_San_Rafael.json`
